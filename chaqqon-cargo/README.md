# Chaqqon Cargo — сайт

Одностраничный сайт карго-компании: калькулятор стоимости, тарифы, адрес склада в Китае с подстановкой личного кода, отслеживание через Telegram-бот, пункты выдачи, вопросы. Два языка — русский и таджикский. Без сборки: HTML, CSS, JS.

## Что заменить перед запуском

Всё в одном файле — `assets/js/config.js`:

- телефон, WhatsApp, Telegram менеджера, Instagram;
- тарифы `$ за кг` по категориям и способам доставки, сроки;
- курс доллара к сомони (`usdToTjs`);
- адрес склада в Китае (поля с `{code}` — туда подставится личный код клиента);
- адреса пунктов выдачи и ссылки на карту;
- `trackingUrl`, если у компании есть своя страница отслеживания.

Таджикские тексты — в `assets/js/i18n.js`. Перед запуском их стоит дать на вычитку носителю языка.

## Запуск

Открыть `index.html` в браузере. На сервере: `node server.js` (порт из `PORT`, иначе 25990).
